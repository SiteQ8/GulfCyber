# الفصل 13: مراقبة الأمن والعمليات الأمنية

## التمارين التطبيقية

1. اكتب خمس حالات استخدام لمؤسسة مالية صغيرة تحدد لكل منها التقنية في مصفوفة التكتيكات ومصادر البيانات ومنطق الكشف وخطوات كتيب التشغيل
2. صمم لوحة مقاييس لمركز عمليات من ثمانية مؤشرات تعرض شهرياً على الإدارة وحدد مصدر كل مؤشر
3. اكتب فرضية صيد تهديدات لسيناريو حركة جانبية بأدوات إدارة شرعية وحدد البيانات التي تبحث فيها وما يثبت الفرضية أو ينفيها

## أسئلة للمراجعة

1. لماذا تُخترق مؤسسات تملك كل الأدوات ولا تلاحظ لأشهر؟
2. ما ترتيب مصادر السجلات بالأولوية ولماذا تتقدم أنظمة الهوية؟
3. ما دورة حياة حالة الاستخدام ولماذا لا تكفي القواعد الافتراضية؟
4. ما الفرق بين الاستخبارات الاستراتيجية والتشغيلية والتكتيكية ومن يستخدم كلاً منها؟
5. كيف يبدأ صيد التهديدات وما النتائج الثلاث الممكنة له؟
6. ما الشروط التي تجعل الاستعانة بمزود خارجي للمراقبة قراراً صحيحاً؟
